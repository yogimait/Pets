# Skills

Task-specific procedures loaded only when the assignment matches. Each skill extends its agent prompt; it does not replace policy or the role.

- `frontend/SKILL.md`
- `backend/SKILL.md`
- `research/SKILL.md`
- `marketing/SKILL.md`
- `ui-ux/SKILL.md`
- `testing/SKILL.md`
- `auditing/SKILL.md`

A skill declares when to use it, required inputs, the procedure, expected tools, output, checks, and boundaries. Keep skills small and specific. Do not put secrets, credentials, or project data in a skill.
